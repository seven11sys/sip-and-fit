# 界面截图

这些 PNG 来自 Sip & Fit v0.7.1 的原生 Android View 界面，使用 Robolectric 原生图形渲染生成，而非设计效果图或手机实拍。

- 输出尺寸：720 × 1600，模拟 360 × 800 dp、xhdpi。
- 渲染环境：Android API 28；为中文文字使用本机可用字体，保留应用的原有字重。不同手机的系统字体及通知权限状态可能有所不同。
- 数据来源：独立的演示记录，包含饮水历史、两个示例运动目标及年度运动记录，不包含真实用户数据。
- 年统计截图展示热力图横向滚动后的部分日期；应用中可以滑动查看全年。
- 演示数据仅用于生成图片，不会随安装包写入用户记录。

| 文件 | 展示内容 |
| --- | --- |
| `water.png` | 饮水进度、常用水量和最近记录。 |
| `workout.png` | 速臂器锻炼与变式平板支撑的目标及记录入口。 |
| `settings.png` | 提醒、运动项目库及通知权限入口。 |
| `water-month.png` | 自然月内的每日饮水量及当前目标参考线。 |
| `workout-year.png` | 全部运动的年度记录条数、各月汇总与每日热力图。 |
