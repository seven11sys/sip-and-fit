# Sip & Fit · 喝水与健身

个人使用的 Kotlin 安卓应用原型，最低 Android 8.0。数据保存在手机本地，不接入服务器。

## 已实现

- 喝水快捷记录：100—500 毫升，每隔 50 毫升一档，共 9 档；保留自定义水量。
- 最近 20 条喝水、健身记录逐条撤回，纠正误点后更新总量和提醒安排。
- 预设速臂器锻炼、变式平板支撑、俯卧撑、深蹲、跑步、骑行、拉伸；可添加、改名、移除自定义运动项目，移除项目保留历史记录。
- 各运动可自由选择时长（秒/分钟）、距离（米/公里）、次数作为每日目标方式。目标值自行填写，不提供运动强度建议。
- 每次记录实际完成量，同项目、同一天、同类单位的记录累计。所有已设目标的项目达标才自动完成，撤回记录后重新计算；不再提供手动完成按钮。
- 未设目标的项目也能记录。保留今天跳过及撤回跳过；健身通知提供“记录运动”入口。
- 喝水与健身提醒设置分别自动保存；输入无效时提示原因并保留上次有效设置，无需手动保存。
- 喝水提醒：默认 09:00—21:00、间隔 90 分钟、12:30—14:00 暂停；记录喝水后重新计时。
- 达到自设目标后可停止当天喝水提醒，次日恢复。
- 健身固定时间提醒，选择每周重复日期；当天完成或跳过后取消后续提醒。
- 通知快捷操作：记录、延后 15 分钟、跳过。
- 通知权限和精确定时权限入口；精确定时未授权时使用可能延迟的提醒。
- 检查通知类别是否关闭，展示通知样式、最近定时触发和通知提交时间；提供通知类别和后台／电量设置入口。
- 喝水、健身均可立即发送测试通知，或安排 1 分钟后发送，测试不修改记录与正式提醒计划。
- 打开页面保留已经安排的提醒；修改一种提醒的设置不会重置另一种提醒的倒计时。
- 重启、系统时间/时区改变、应用更新后恢复安排；不补发积压提醒。

提醒默认关闭，需要主动开启，设置自动保存。每日目标仅用于记录，不是饮水健康建议。

## 排查收不到提醒

安装新版后，先使用“立即测试”检查通知显示，再使用“1 分钟后测试”，退到桌面并锁屏等待。测试通知不受喝水时段、每日目标或健身重复日期限制。

如果没有收到，请查看“提醒检查”里的状态文字、最近触发和通知提交时间。已提交但没有显示时，检查系统通知类别的锁屏、声音及弹出设置；立即测试正常而后台测试没有触发时，检查手机的后台自启动和应用省电设置。各厂商菜单名称不同，仍需真机验证。

## 开发和运行

需要 Android Studio、JDK 17、Android SDK 35、Gradle 8.11.1。打开本目录并同步项目，连接安卓手机，运行 `app`。

```sh
./gradlew testDebugUnitTest assembleDebug
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`。

提醒规则使用纯 Kotlin 编写；单元测试覆盖喝水后重新计时、午休、夜间、目标达成、稍后提醒、跨天、健身重复日期和错过提醒等行为。

## 当前限制与验证

- 使用临时 JDK 17、Kotlin 2.1.20 和 Android SDK 35 完成全部 Kotlin 源码编译检查。
- 41 项自动测试覆盖提醒规则、记录撤回、自动保存、自定义目标、多次累计、单位换算、自动完成、旧记录兼容、保留提醒时间、后台接收通知、通知类别关闭和测试通知。
- GitHub Actions 已通过 `testDebugUnitTest`、`assembleDebug` 和 `lintDebug`，生成 debug APK；尚未进行真机验证。
- [构建与 APK 下载](https://github.com/seven11sys/sip-and-fit/actions)：登录 GitHub 后，选择最新通过的构建，在 Artifacts 中下载 `sip-and-fit-debug`，解压得到 `app-debug.apk`。安装包保留 7 天。
- 已配置 GitHub Actions，在代码推送后运行测试、构建和 lint，通过后提供 debug APK 下载。文档提交可以使用 `[skip ci]` 跳过重复构建。
- 需要真机验证：通知允许/拒绝、精确定时允许/拒绝、锁屏省电、手机重启、时区修改、快捷操作、关闭提醒。
- Android 系统和厂商的省电策略可能延迟提醒；强行停止应用后，需再次打开应用恢复安排。
- 当前 UI 是可操作的原型。周统计、数据导入导出、桌面小组件和鸿蒙原生版本尚未实现。
- CI 缓存 debug 签名密钥，便于后续测试版覆盖安装。首次改用缓存密钥或缓存被清理后，签名可能变化；若提示签名冲突，请勿直接卸载，以免删除本地记录。
- 暂不支持跨午夜的喝水提醒时段。

## 后续迁移
